# ES6 Data Manipulation

## In this project, I learnt :

How to use map, filter and reduce on arrays

Typed arrays

The Set, Map, and Weak link data structures

## Requirements :

All my files are interpreted/compiled on Ubuntu 20.04 LTS using node 20.x.x and npm 9.x.x

Allowed editors: vi, vim, emacs, Visual Studio Code

All my files end with a new line

My code uses the js extension

My code is tested using Jest and the command npm run test

My code is verified against lint using ESLint

My code passes all the tests and lint. The entire project is verified running npm run full-test

All of my functions are exported
