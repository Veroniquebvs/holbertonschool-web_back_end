# NoSQL

## In this project, I learnt :

What NoSQL means

What is difference between SQL and NoSQL

What is ACID

What is a document storage

What are NoSQL types

What are benefits of a NoSQL database

How to query information from a NoSQL database

How to insert/update/delete information from a NoSQL database

How to use MongoDB

## Requirements :

### MongoDB Command File

All my files are interpreted/compiled on Ubuntu 20.04 LTS using MongoDB (version 4.4)

All my files end with a new line

The first line of all my files is a comment: // my comment

The length of my files will be tested using wc

### Python Scripts

All my files are interpreted/compiled on Ubuntu 20.04 LTS using python3 (version 3.9) and PyMongo (version 4.8.0)

All my files end with a new line

The first line of all my files is exactly #!/usr/bin/env python3

My code use the pycodestyle style (version 2.5.*)

The length of my files is tested using wc

All my modules have a documentation (python3 -c 'print(__import__("my_module").__doc__)')

All my functions have a documentation (python3 -c 'print(__import__("my_module").my_function.__doc__)')

My code isn't executed when imported (by using if __name__ == "__main__":)
